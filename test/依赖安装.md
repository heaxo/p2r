### GPU 版

#### 卸载旧版本

```sh
python -m pip uninstall -y torch torchvision torchaudio
python -m pip cache purge
```

#### 安装GPU版

```sh
python -m pip install torch==2.6.0 torchvision==0.21.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu118
```

#### 装完测试

```sh
python -c "import torch; import torchvision; print(torch.__version__); print(torchvision.__version__); print(torch.cuda.is_available())"
```
